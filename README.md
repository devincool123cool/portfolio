A professional online portfolio showcasing my education, work experience, projects, and skills.

This portfolio website highlights:

- **Education**: Northern Virginia Community College, Arlington Tech Program, and QSI International School
- **Technical Skills**: Automotive repair, welding, 3D design, physics, and engineering
- **Work Experience**: Caterer and Floral Arranger at Darling & Daughter Flowers

## Pages Included

1. **Home (index.html)** - Welcome page with key highlights
2. **About (about.html)** - Personal background and motivations
3. **Resume (resume.html)** - Complete education, work experience, and activities
4. **Projects (projects.html)** - Detailed showcase of academic and technical projects
5. **Contact (contact.html)** - Contact information and message form

## Design Features

- Clean, professional design using HTML5 and CSS3
- Responsive layout that works on all device sizes (desktop, tablet, mobile)
- Consistent color scheme: Professional blue with accent gold
- Easy navigation with sticky header
- Engaging project cards with hover effects
- Fast loading times
- Accessibility-focused design

## How to Use

1. Clone or download this repository

3. Navigate through the pages using the navigation menu
4. Customize content by editing the HTML files
5. Modify colors and styling by editing `styles.css`
